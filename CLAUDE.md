## Before you finish any change

1. `git pull --rebase` (other sessions push here too).
2. `sh src/<app>/build.sh` → raise `version` in `adam-<app>/umbrel-app.yml`, plus `APP_VERSION`
   in its `docker-compose.yml` if present, plus `const version` in `src/zalastudio-iranyitopult/main.go`
   for the Irányítópult. Add a one-line Hungarian release note.
3. `./check.sh` must pass.
4. Commit with a clear message and push to `main`. Tell Ádám to press Update on both Umbrels.

## Things that are easy to get wrong

- A price or package change on zalastudio.hu touches `www/index.html` (the cards) **and**
  `www/assets/js/preview.js` (`PLANS`). `src/zalastudio-iranyitopult/web/preview.js` is
  regenerated by its build.sh. Plan codes and labels must also match `src/zalastudio-iranyitopult/labels.go`.
- The website talks to the Irányítópult only over internal ports (9095, 9097). Neither is ever
  published or put on Cloudflare.
- Legal pages (`aszf.html`, `adatvedelem.html`) change only when Ádám asks.
- Never commit anything from an app's `data/` folder. It holds passwords and Stripe keys.
- Ádám's phone number never goes on a site. His name goes only on the legal pages. No site mentions
  the standby server's host or that the sites run on home servers.
- UI work follows the 20 UX & animation principles (snappy <300 ms, eased, ≥44 px targets,
  few choices, accept messy input and return it clean).
- Speed matters: no external libraries, fonts or scripts. Keep comments in served files short.
